# DeskBuddy (ESP32 CYD 2.8")

8-bit часы + погода (Open-Meteo, без API-ключа) + календарь. Стиль: кирпичи, холмы, жёлтые «монетные» акценты, пиксельный шрифт. Это собственный дизайн в духе ретро-платформеров, без спрайтов и персонажей Nintendo.

Управление: короткое касание переключает часы и календарь, удержание около 2 секунд открывает настройку Wi-Fi и города.

## Прошивка с компьютера (Mac / Windows / Linux)

    pip install platformio
    pio run -t upload

## Установка из браузера (Chrome / Edge)

1. Создайте репозиторий на GitHub и запушьте туда этот проект в ветку `main`.
2. В Settings > Pages выберите Source: GitHub Actions.
3. После сборки (вкладка Actions) установщик будет на `https://<ваш-логин>.github.io/<репозиторий>/`.
4. Откройте страницу в Chrome или Edge, подключите плату и нажмите кнопку установки.

На Windows может понадобиться драйвер CH340/CP210x для USB-порта платы.

## Первая настройка

Плата поднимет сеть `DeskBuddy-Setup`. Подключитесь, откройте `192.168.4.1`, выберите Wi-Fi и введите город (например, `Berlin`). Часовой пояс и переход на летнее время берутся автоматически.

## Если что-то не так

- Цвета инвертированы: в `src/main.cpp` поставьте `INVERT_COLORS true`.
- Экран вверх ногами: `ROTATION 3`.
- Экран чёрный или с мусором: у вашей версии CYD может быть другой драйвер (например, ST7789), тогда нужно поменять `-DILI9341_2_DRIVER=1` в `platformio.ini`.
