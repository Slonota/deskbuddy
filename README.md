# DeskBuddy (ESP32 CYD 2.8")

8-bit часы + погода (Open-Meteo, без API-ключа) + календарь. Стиль: кирпичи, холмы, жёлтые «монетные» акценты, пиксельный шрифт. Это собственный дизайн в духе ретро-платформеров, без спрайтов и персонажей Nintendo.

Управление: короткое касание переключает часы и календарь, удержание около 2 секунд открывает настройку Wi-Fi и города.

## Прошивка с компьютера (Mac / Windows / Linux)

    pip install platformio
    pio run -t upload

## Установка из браузера (Chrome / Edge)

1. Создайте репозиторий на GitHub и запушьте туда этот проект в ветку `main`.
2. В Settings > Pages выберите Source: GitHub Actions.
3. После сборки (вкладка Actions) установщик будет на `https://<ваш-логин>.github.io/<репозиторий>/`.
4. Откройте страницу в Chrome или Edge, подключите плату и нажмите кнопку установки.

На Windows может понадобиться драйвер CH340/CP210x для USB-порта платы.

## Первая настройка

Плата поднимет сеть `DeskBuddy-Setup`. Подключитесь, откройте `192.168.4.1`, выберите Wi-Fi и укажите место одним из способов:

- город (например, `Berlin`), координаты найдутся автоматически;
- широта и долгота в десятичных градусах (например, `52.52` и `13.40`). Если заполнены оба поля, они главнее города, а название города можно оставить пустым или написать любое, оно выведется на экране. Если названия нет, на экране будут координаты.

Чтобы вернуться к поиску по городу, очистите поля широты и долготы и введите город.

Дополнительные поля:

- **Timezone** (часовой пояс): название вида `Europe/Berlin`, `Europe/Moscow`, `America/New_York`. Переход на летнее время учитывается. Пустое поле означает автоопределение по координатам. Если название неизвестно, прошивка тихо вернётся к автоопределению.
- **Flip display**: `1` переворачивает экран на 180° (тач переворачивается вместе с ним), `0` возвращает обычное положение.

## Если что-то не так

- Цвета инвертированы: в `src/main.cpp` поставьте `INVERT_COLORS true`.
- Экран вверх ногами: в настройках поле **Flip display** поставьте `1`.
- Экран чёрный или с мусором: у вашей версии CYD может быть другой драйвер (например, ST7789), тогда нужно поменять `-DILI9341_2_DRIVER=1` в `platformio.ini`.

## Значения по умолчанию и погода

- Источник погоды: Open-Meteo (без ключа). Ветер показывается в м/с.
- По умолчанию стоят Санкт-Петербург (координаты 59.9386, 30.3141) и часовой пояс `Europe/Moscow` (UTC+3). Это работает сразу после первой настройки Wi-Fi, город вводить не нужно. Если сервер погоды недоступен, часы всё равно показывают московское время.
- Любое значение можно поменять в портале настройки. Чтобы вернуть автоопределение часового пояса по координатам, очистите поле **Timezone**.
